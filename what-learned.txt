1. For verifing user email address we need to import sendEmailVerification() promise from firebase auth.
and 1st arg is auth currentUser. 
    ===>
        import {getAuth, sendEmailVerification} from 'firebase/auth';

        const auth = getAuth();

        sendEmailVerification(auth.currentUser)
        .then(()=>{
          console.log("verification email sended");
        }).catch(error => {
          console.log(error)
        });

2. For send Password Reset Email we need to import sendPasswordResetEmail() promise from firebase auth. 1st arg is auth and 2nd arg is email where will send mail.
    ===>
        import {getAuth, sendPasswordResetEmail} from 'firebase/auth';

        const auth = getAuth();

        sendPasswordResetEmail(auth, email)
        .then(()=>{
          console.log("passoword reset email sended");
        }).catch(error => {
          console.log(error)
        });
